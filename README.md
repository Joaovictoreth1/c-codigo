# Lista de alunos em C#

Exercício de listas que remove um aluno de uma turma de exemplo. O nome pode conter espaços nas pontas e não diferencia maiúsculas de minúsculas. Entradas vazias ou nomes desconhecidos não alteram a lista.

Com o SDK .NET 10, execute `dotnet run` na raiz e digite o nome ou envie uma linha pelo terminal:

```sh
printf ' ana \n' | dotnet run
```

A lista atualizada contém Pedro, Helena, Carlos e Marcos. Digite `Zoe` para ver `Aluno não encontrado.` ou pressione Enter sem digitar para ver `Nenhum nome informado.`.
